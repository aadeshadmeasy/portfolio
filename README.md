# Aadesh Panwar · Personal AI OS Portfolio

Interactive portfolio operating system for **Aadesh Panwar**, CEO of **Admeasy Ai** (Admeasy Admission Solutions Pvt Ltd).

Built with **Next.js 16**, **TypeScript**, and **Tailwind CSS**. Deployed on **Vercel**.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Customize content

All owner content lives in `src/content/owner-profile.ts`. Update identity, projects, metrics, journey, and conversion URLs there.

## Environment variables

See `.env.example`. Never commit secrets.

## Apps

Projects · Results · Systems · Proof · Journey · Socials · Founder.txt · Whiteboard · AadeshNet · Contact · Calendar · AI Voice Agent

## Deploy

```bash
npm run build
```

Connect the GitHub repo to Vercel for automatic preview and production deployments.
